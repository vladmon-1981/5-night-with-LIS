# 5 ночей с Лисом

Веб-игра ужасов по мотивам *Five Nights at Freddy's*. Выживи до 6:00 утра, закрывай дверь, корми голодного Лиса пирожками и чини протекающие трубы.

## 🎮 Играть

Открой `index.html` в любом современном браузере. Никаких зависимостей не требуется.

## ✨ Особенности

- **5 ночей** с возрастающей сложностью
- **Камеры наблюдения** (3 локации) с видимостью Лиса и псевдо-3D параллаксом
- **Система дверей** — быстро закрывай при приближении
- **Готовка пирожков** — успокой голодного Лиса, восстанови энергию
- **Управление энергией** — генератор иссякает со временем
- **Индикатор голода** — Лис агрессивнее, когда голоден
- **Звуковые эффекты** — синтезированные через Web Audio API
- **Анимированное блуждание** Лиса по камерам с трансформациями (масштаб, поворот)

## 🎯 Цель

Доживи до 6:00 утра всех 5 ночей. Лис может убить тебя, если прорвёт закрытую дверь или пройдёт через открытую.

## 🕹️ Управление

- **◀/▶** — повернись по комнате (коридор → кухня → гостиная)
- **▼** — включи камеры наблюдения
- **ЗАКРЫТЬ ДВЕРЬ** — прегради путь Лису
- **На кухне** — лепи пирожки (2с), пеки в духовке (8с), корми Лиса
- **На камере с трубами** — чини утечки вовремя, иначе потеряешь энергию

## 🛠️ Технологии

- Чистый **HTML5** / **CSS3** / **JavaScript** (ES6+)
- **Web Audio API** для звуков (без библиотек)
- **CSS 3D Transforms** для псевдо-3D эффектов (перспектива, rotateY, scale)
- Асинхронная логика игры через `setInterval` и `setTimeout`

## 🚀 Особенности реализации

### Псевдо-3D рендер Лиса
Вместо настоящей 3D-модели, Лис использует **CSS 3D transforms** для создания иллюзии объёма:
- `rotateY()` — поворачивается в сторону движения
- `scale()` — масштабируется по "глубине" (вертикальная позиция на камере)
- Плавные переходы 1.3 сек при перемещении между позициями

### Система голода
- Голод Лиса растёт со временем (видна оранжевая полоса в HUD)
- Кормление пирожком сбрасывает голод на 40%
- Высокий голод (>85%) значительно повышает шанс атаки

### Звуки
- Клики, двери, тревоги, капли воды, починка — всё синтезируется Web Audio API
- Крик Лиса при смерти игрока — шумовая генерация + модуляция частоты
